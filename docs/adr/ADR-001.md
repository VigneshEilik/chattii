# ADR-001: Decoder-Only Architecture Selection

## Status
Approved

## Context
For the `chatii` foundation model, we must establish the core transformer architecture topology. The model needs to excel at autoregressive text generation, chat conversations, instruction following, and open-ended text completion.

## Decision
We will construct a **Decoder-only transformer** architecture (similar to GPT, LLaMA, and Gemma) rather than Encoder-only (BERT-style) or Encoder-Decoder (T5-style) architectures.

## Rationale
1. **State of the Art for Autoregression**: Decoder-only topologies have proven to be the most parameter-efficient and effective structures for general language generation tasks.
2. **Simplified Implementation Complexity**: By avoiding encoder-decoder cross-attention layers, we reduce model parameter complexity, simplifying the scratch math implementation for Milestone 2.
3. **Optimized Key-Value (KV) Caching**: In decoder-only setups, KV caching is straightforward since only self-attention key-value states need to be persisted during sequential token generation.

## Consequences
- Autoregressive generation will require causal masking in all attention layers.
- The context window is shared between inputs (prompts) and outputs (targets), making max sequence length configuration critical.
