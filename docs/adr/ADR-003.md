# ADR-003: RMSNorm Selection

## Status
Approved

## Context
Transformer networks require intermediate normalization layers to regulate activation scales, preventing gradient explosion or vanishing during backpropagation.

## Decision
We select **Root Mean Square Normalization (RMSNorm)** instead of standard Layer Normalization (LayerNorm).

## Rationale
1. **Computational Efficiency**: RMSNorm scales activations by the root mean square of the layer input without calculating the mean. This eliminates the mean-subtraction step, reducing computational complexity.
2. **Comparable Convergence**: Empirical studies demonstrate that RMSNorm maintains identical convergence properties and training stability compared to standard LayerNorm.
3. **Hardware Acceleration Compatibility**: The simplified mathematical formulation of RMSNorm maps highly efficiently to GPU execution kernels.

## Consequences
- Mean-centering is omitted in the layer calculations, meaning only scaling variance is tracked.
- Need to implement learnable scaling parameter ($\gamma$) vectors.
