# ADR-002: Rotary Position Embeddings (RoPE) Selection

## Status
Approved

## Context
A mechanism is required to encode sequence position information into the transformer's attention operations so the model understands token order.

## Decision
We select **Rotary Position Embeddings (RoPE)** as the positional encoding technique instead of Absolute Sinusoidal Embeddings (GPT-3) or Learned Position Embeddings (BERT).

## Rationale
1. **Relative Distance Preservation**: RoPE encodes position by rotating Query and Key vectors in 2D spaces, naturally preserving relative distances between tokens in self-attention dot-products.
2. **Extrapolation to Longer Sequences**: RoPE allows the model to extrapolate to context windows larger than the training window size using techniques like interpolation or NTK-aware scaling.
3. **Decoupled Embeddings**: RoPE is applied inside the attention calculation (on queries/keys) rather than directly adding position vectors to input word embeddings, avoiding input representation corruption.

## Consequences
- Requires custom vector rotation mathematical operations in the attention layers.
- Adds minor calculation overhead at each attention layer during the forward pass.
