# ADR-004: PyTorch Selection

## Status
Approved

## Context
A deep learning framework is required to build the tensor operations, automatic differentiation, and CUDA GPU kernels for Chatii.

## Decision
We select **PyTorch** (targeting PyTorch 2.x and above) as the primary deep learning framework.

## Rationale
1. **Dynamic Computation Graph (Eager Execution)**: PyTorch allows dynamic graph construction, which is highly beneficial for debugging scratch implementations of custom attention blocks and backpropagation layers.
2. **Hardware Acceleration Support**: Built-in CUDA, MPS, and CPU support with automatic mixed-precision (AMP) wrappers.
3. **Ecosystem Domination**: PyTorch is the dominant framework in NLP and transformer research, ensuring robust community support, compatibility with Hugging Face datasets (for loading), and direct integration with optimization compilers like `torch.compile`.

## Consequences
- The codebase relies on PyTorch tensors as the underlying data structure.
- We must encapsulate PyTorch dependencies to maintain our modular OS framework boundary (e.g. interfaces should not strictly expose framework-specific internals if they can be avoided).
